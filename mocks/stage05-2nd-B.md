## Part 2 · Circle the correct answer (20)

1. Whisky isn't a ____ drink.  (**weak** / week / strong)
2. She's usually ____ on weekends.  (freedom / busy / **free**)
3. Charles drives ____ after drinking alcohol.  (**dangerously** / dangerous / danger)
4. Yesterday John ____ late to go to work.  (wake up / **woke up** / woken up)
5. People generally say that cats have seven ____.  (life / lifes / **lives**)
6. If I was a bird I ____ fly.  (could to / **could** / will could)
7. The lesson hasn't finished ____.  (**yet** / again / still)
8. São Paulo is one of the ____ cities in Brazil.  (dirt / **dirtiest** / dirty)
9. We throw ____ things away.  (use / useful / **useless**)
10. If your computer is ____ you must fix it.  (fault / **faulty** / faultless)
11. We use ice for putting in drinks to ____ them.  (**cool** / warm / pour)
12. He had to ____ because his house was on fire.  (take his time / **hurry** / keep an appointment)
13. We've known you ____ last year.  (**since** / for / during)
14. I wouldn't ____ you money if you asked me.  (bend / rent / **lend**)
15. People generally ____ when they do something wrong.  (wait / **apologize** / advice)
16. A doctor usually ____ a lot of money in a month.  (**earns** / wins / buys)
17. The window was ____ by John.  (broke / **broken** / break)
18. They were ____ in Canada in 2010.  (afraid / worried / **born**)
19. We call the part of a tree that is in the land the ____.  (snacks / pupils / **root**)
20. The pasta is ____ eaten by Andrew.  (to be / **being** / will be)
